⚡ Start in 5 Minutes

  1. 1 Start Docker Desktop — Ensure Docker Desktop is running in your system tray.
  2. 2 Install Ollama & pull models — In terminal, run:
    ollama pull qwen3.8:27b
    ollama pull qwen3-embedding:0.6b
  3. 3 Download & Extract ZIP — Extract the package completely to a folder (e.g. C:\StarkLLM\).
  4. 4 Open terminal in folder — In the extracted folder, click the Explorer address bar, type cmd, and press Enter.
  5. 5 Run start.exe — Type start.exe (if Windows warns: More info → Run anyway).
    Fallback: start.cmd  |  Last resort: docker compose up --build -d
  6. 6 Open StarkLLM — Navigate to http://localhost:5173 in your browser.

Important Notes

  • ⌛ First launch: First launch can take several minutes while Docker images download. Later starts are much faster.
  • ⚠️ Windows SmartScreen: If execution is blocked, use More info → Run anyway or run start.cmd.

Prerequisites Checklist

Before you attempt to start StarkLLM, confirm that all of the following are in place:

  • OS: Windows 10 or 11 with WSL2 enabled.
  • Docker Desktop: Installed and actively running (visible in the system tray). Without this, nothing will start.
  • Ollama: Installed natively on Windows and running. Download from ollama.com.
  • Models pulled: Open a terminal and run:
    ollama pull qwen3.8:27b
    ollama pull qwen3-embedding:0.6b
  • Hardware: Minimum 16 GB RAM. An NVIDIA GPU with 8 GB+ VRAM is strongly recommended for usable performance. See the User Manual for hardware tier guidance.

⚠️ Windows SmartScreen / Execution Notice

Because files inside the ZIP are downloaded from the web, Windows attaches a Mark of the Web (MOTW) flag. This is standard Windows security behavior for downloaded archives, not a malware warning.

Option 1 — Run start.exe from Terminal (Recommended)

StarkLLM includes a standalone start.exe launcher that checks Docker Desktop status, checks Ollama, builds containers, and opens your browser:

  1. In File Explorer inside the extracted folder, click the address bar, type cmd, and press Enter.
  2. Type start.exe and press Enter. If Windows SmartScreen displays a warning, click More info → Run anyway.

Option 2 — Run start.cmd (Terminal Fallback)

If you prefer running a command script directly in the terminal:

  1. In the extracted folder terminal, run: start.cmd

Option 3 — Direct Docker Compose (Last Resort)

If you prefer standard Docker CLI commands directly:

docker compose up --build -d

Option 4 — Run unblock.ps1 (If Scripts are Blocked)

If execution policies prevent script execution, open PowerShell in the extracted folder and run:

powershell -ExecutionPolicy Bypass -File unblock.ps1

This command safely removes SmartScreen flags only from files inside the current StarkLLM folder. It does not alter your global Windows security settings.

After unblocking, run start.exe or start.cmd (or advanced option: start.bat).

Frequently Asked Questions

1. Does my data leave my computer?

StarkLLM is designed to keep your data on your machine. Documents are stored in a local ChromaDB container. AI inference runs via Ollama on your host machine. During normal local operation, no data is intended to be transmitted externally.

2. Is StarkLLM free?

Yes. It is free and open-source. There are no subscriptions or premium tiers. It is provided "as is" with no liability.

3. Why can answers be slow?

Speed depends on your hardware. If you do not have a dedicated GPU, Ollama defaults to CPU inference, which is significantly slower. A dedicated NVIDIA GPU (8GB+ VRAM) can significantly improve generation speed.

4. Why does Windows SmartScreen warn about downloaded launchers?

Windows attaches a Mark of the Web attribute to files downloaded from the internet. When running start.exe, click More info → Run anyway. Alternatively, run start.cmd from a terminal or run unblock.ps1 to remove the flag locally.

5. What hardware do I need?

At minimum: 16 GB RAM and an NVIDIA GPU with 8GB VRAM for 8-Billion parameter models. For demanding models (14B-32B), 24GB VRAM or 64GB system RAM is recommended.

6. What is the difference between normal chat and document chat?

Normal chat relies solely on the LLM's pre-trained knowledge. Document chat uses RAG: it searches your uploaded PDFs first, feeds relevant chunks to the LLM, and provides answers with specific citations to your documents.

7. What is the difference between Workspace Documents and Knowledge Base?

Workspace Documents are temporary and isolated to a specific project. The Knowledge Base is a persistent, global folder on your machine that can be referenced from any chat.

8. What if the UI opens but chat does not work?

Ensure Docker Desktop and Ollama are running. Verify you have pulled the required models (ollama pull qwen3.8:27b and ollama pull qwen3-embedding:0.6b). If chat cannot connect, Ollama must be running natively on your Windows host; the backend container communicates with Ollama via host.docker.internal:11434. If it still fails, reset the backend manually in a terminal with docker compose down followed by docker compose up --build -d.

9. Can I use this commercially?

StarkLLM is a Research Beta. You can use it freely, but there are no commercial warranties, support SLAs, or liability accepted for business disruption or data loss.

10. Where can I send feedback or contribute?

We welcome feedback! Email us at info@starkllm.com or open an issue on our GitHub repository.
