Download Windows Beta (.zip)

Version 1.0.0 (Research Beta)

System Requirements

  • OS: Windows 10/11 (with WSL2 enabled)
  • Docker Desktop: Must be installed and running.
  • Ollama: Must be installed natively on your Windows host.
  • Hardware: Minimum 16GB RAM and an NVIDIA GPU (8GB+ VRAM recommended).

Installation Steps

  1. Download and extract the ZIP file to your preferred location.
  2. Ensure Docker Desktop and Ollama are running.
  3. Double-click the start.bat file inside the folder.
  4. In the menu, press 1 to start StarkLLM. The system will build and open automatically in your browser at http://localhost:5173.

The launcher controls are simple: 1 = Start, 2 = Stop, 3 = Exit.
