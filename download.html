Get started with the Windows Research Beta.

⚡ Start in 5 Minutes

  1. 1 Start Docker Desktop — make sure it is running in the system tray.
  2. 2 Install Ollama and pull the required models:
    ollama pull qwen3.8:27b && ollama pull qwen3-embedding:0.6b
  3. 3 Download the ZIP and extract it to a folder (e.g. C:\StarkLLM\).
  4. 4 Run start.bat — double-click it and press 1.
    Or run manually from terminal: docker compose up --build -d
  5. 5 Open your browser at http://localhost:5173

Important Notes

  • ⌛ First launch takes longer: Docker must download container images initially.
  • ⚠️ Windows SmartScreen: If Windows blocks start.bat, use the alternative options below.
  • 💻 Hardware matters: Speed and answer quality depend heavily on having a capable GPU (8GB+ VRAM).

Prerequisites Checklist

Before you attempt to start StarkLLM, confirm that all of the following are in place:

  • OS: Windows 10 or 11 with WSL2 enabled.
  • Docker Desktop: Installed and actively running (visible in the system tray). Without this, nothing will start.
  • Ollama: Installed natively on Windows and running. Download from ollama.com.
  • Models pulled: Open a terminal and run:
    ollama pull qwen3.8:27b
    ollama pull qwen3-embedding:0.6b
  • Hardware: Minimum 16 GB RAM. An NVIDIA GPU with 8 GB+ VRAM is strongly recommended for usable performance. See the User Manual for hardware tier guidance.

⚠️ Windows May Block start.bat

Because start.bat was downloaded from the internet, Windows Smart App Control or SmartScreen may flag it as potentially unsafe and refuse to run it. This does not mean the file is malware. It is a standard Windows security mechanism applied to any script downloaded from outside the local network. StarkLLM is entirely open-source and you are welcome to inspect every line of the file before running it.

Option A — start.bat Control Panel (Easiest)

If Windows allows it, simply double-click start.bat in the extracted folder. A text menu opens in a terminal window:

Press 1 → Start StarkLLM   (builds and launches containers, opens app in browser)
Press 2 → Stop StarkLLM   (cleanly shuts down all containers)
Press 3 → Exit   (closes the control panel without changing anything)

🔎 First Start Takes Longer

The first time you press 1, Docker will download and build the required container images. This can take several minutes. Subsequent starts are fast.

Once running, navigate to http://localhost:5173 in your browser if it doesn't open automatically.

Option B — Unblock the File (If Blocked)

If Windows prevents start.bat from running, try unblocking it first:

  1. Right-click start.bat and select Properties.
  2. At the bottom of the General tab, look for a message about the file being blocked from another computer.
  3. Check the Unblock checkbox if it is present.
  4. Click Apply, then OK.
  5. Double-click start.bat again.

Option C — Run from Terminal

Running a script directly from a terminal window often bypasses SmartScreen entirely:

  1. Open the extracted project folder in File Explorer.
  2. Click the address bar, type cmd or powershell, and press Enter to open a terminal in that folder.
  3. Run the following command:
.\start.bat

Option D — Manual Start Without start.bat

If the starter script is still blocked or unavailable, you can control StarkLLM directly using Docker commands. Make sure Docker Desktop is running before proceeding.

To start:

docker compose up --build -d

Then open http://localhost:5173 in your browser.

To stop:

docker compose down

These two commands are exactly what start.bat runs internally. There is no difference in outcome.

Frequently Asked Questions

1. Does my data leave my computer?

StarkLLM is designed to keep your data on your machine. Documents are stored in a local ChromaDB container. AI inference runs via Ollama on your host machine. During normal local operation, no data is intended to be transmitted externally.

2. Is StarkLLM free?

Yes. It is free and open-source. There are no subscriptions or premium tiers. It is provided "as is" with no liability.

3. Why can answers be slow?

Speed depends on your hardware. If you do not have a dedicated GPU, Ollama defaults to CPU inference, which is significantly slower. A dedicated NVIDIA GPU (8GB+ VRAM) can significantly improve generation speed.

4. Why does Windows block start.bat?

Windows SmartScreen flags scripts downloaded from the internet. It does not mean the file is malware. You can unblock it via file Properties, or bypass SmartScreen by running .\start.bat directly from a terminal.

5. What hardware do I need?

At minimum: 16 GB RAM and an NVIDIA GPU with 8GB VRAM for 8-Billion parameter models. For demanding models (14B-32B), 24GB VRAM or 64GB system RAM is recommended.

6. What is the difference between normal chat and document chat?

Normal chat relies solely on the LLM's pre-trained knowledge. Document chat uses RAG: it searches your uploaded PDFs first, feeds relevant chunks to the LLM, and provides answers with specific citations to your documents.

7. What is the difference between Workspace Documents and Knowledge Base?

Workspace Documents are temporary and isolated to a specific project. The Knowledge Base is a persistent, global folder on your machine that can be referenced from any chat.

8. What if the UI opens but chat does not work?

Ensure Docker Desktop and Ollama are running. Verify you have pulled the required models (ollama pull qwen3.8:27b). If it still fails, reset the backend manually in a terminal with docker compose down followed by docker compose up --build -d.

9. Can I use this commercially?

StarkLLM is a Research Beta. You can use it freely, but there are no commercial warranties, support SLAs, or liability accepted for business disruption or data loss.

10. Where can I send feedback or contribute?

We welcome feedback! Email us at info@starkllm.com or open an issue on our GitHub repository.
