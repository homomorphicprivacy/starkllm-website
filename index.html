Research Beta — Windows

Private Windows AI for Your Local Documents

StarkLLM is a private Windows research beta for technical users to chat with local documents and a personal Knowledge Base via Ollama. Built for developers, researchers, and privacy-conscious professionals who want local RAG running on their own Docker + Ollama stack.

  • 📄 Local Documents:
    Upload PDFs & text files to isolated Workspaces.
  • 📚 Knowledge Base:
    Map a permanent folder on your PC for cross-chat RAG. Register the folder with start.exe --add-folder or [A] in the launcher. Sync is interval (~1 minute), not a kernel watcher. The web UI rejects raw C:\ paths.
  • 🔒 Strict Zero-Cloud:
    Runs 100% on your hardware via Docker & Ollama.

⚠️ Before You Download — System Prerequisites

  • OS: Windows 10/11 with WSL2 enabled.
  • Docker Desktop: Installed & running in system tray.
  • Ollama: Installed natively on Windows host.
  • Hardware: 8 GB RAM min / 16 GB recommended (NVIDIA GPU with 8GB+ VRAM recommended).
  • Models: ollama pull qwen2.5:7b & nomic-embed-text (or lighter: qwen2.5:3b)

⚡ Setup Steps

If Docker, Ollama, and the models are already installed, setup takes about 5 minutes. First-time model and Docker-image downloads depend on your bandwidth.

  1. 1 Start Docker Desktop — Ensure Docker Desktop is running in your system tray.
  2. 2 Install Ollama & pull models — In terminal, run:
    ollama pull qwen2.5:7b
    ollama pull nomic-embed-text
  3. 3 Run StarkLLM Setup (.exe) — Download and run StarkLLM-Setup.exe (or extract Portable ZIP). The wizard automatically configures desktop shortcuts.
  4. 4 Launch & Enjoy — Click the StarkLLM desktop shortcut. Services start automatically and open http://localhost:5173 in your browser.

Important Notes

  • ⌛ First launch: First launch can take several minutes while Docker images download. Once containers are up, the app itself may need 1–2 minutes while the backend finishes startup.
  • ⚠️ Windows SmartScreen: If execution is blocked, use More info → Run anyway or run start.cmd.
  • 💻 Hardware matters: Speed and answer quality depend heavily on having a capable GPU (8GB+ VRAM recommended).

The Command Center

The Dashboard provides immediate visibility into your local intelligence ecosystem. Navigate seamlessly between distinct workspaces and monitor system status in real-time.

  • Workspace Isolation: Separate your research projects, coding tasks, and legal document reviews into isolated workspaces. Workspace uploads stay in that workspace; the Global Knowledge Base is shared and can be queried from any chat.
  • Live System Status: Monitor your vector database health, backend connectivity, and Ollama inference engine uptime at a glance.
  • Instant Access: Jump directly into recent chat threads or review the documents currently indexed in your active workspace.

Document-Aware Intelligence

Experience chat that is grounded in your documents. StarkLLM bridges the gap between open-weight LLMs and your personal or enterprise documents.

  • Source-Grounded Answers: The AI retrieves precise semantic chunks from your uploaded PDFs before generating an answer, drastically reducing unsupported answers.
  • Transparent Citations: Responses include the source filename and page or section locator, so you can trace the AI's reasoning to your original document.
  • Multi-Chat Sessions: Maintain parallel, distinct conversations within the same workspace to explore different hypotheses simultaneously.

The Architecture of Privacy

StarkLLM offers an offline alternative to cloud AI services. Your enterprise data, legal briefs, and personal research stay strictly on your machine.

Local Inference

Powered by Ollama, Large Language Models run directly on your own CPU or GPU. Designed to work fully offline once models are downloaded.

Local Storage

Your documents are chunked and embedded into a local ChromaDB vector store running inside an isolated Docker container.

Zero Telemetry

The Windows app has no telemetry and no analytics SDK. This marketing website uses self-hosted Umami; see Datenschutz.
