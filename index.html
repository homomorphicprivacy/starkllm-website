Research Beta — Windows

Private Windows AI for Your Local Documents

StarkLLM is a private Windows research beta for technical users to chat with local documents and a personal Knowledge Base via Ollama. Built for developers, researchers, and technical professionals who want local RAG running on their own Docker + Ollama stack.

  • 📄 Local Documents:
    Upload PDFs & text files to isolated Workspaces.
  • 📚 Knowledge Base:
    Map a permanent folder on your PC for cross-chat RAG.
  • 🔒 Private by Default:
    Runs on your hardware via Docker Desktop & Ollama.

⚠️ Before You Download — System Prerequisites

  • OS: Windows 10/11 with WSL2 enabled.
  • Docker Desktop: Installed & running in system tray.
  • Ollama: Installed natively on Windows host.
  • Hardware: NVIDIA GPU (8GB+ VRAM recommended for 27B model).
  • Models required: ollama pull qwen3.6:27b & qwen3-embedding:0.6b

Windows Research Beta

StarkLLM

Local RAG on Your Stack: Transparent, local-first RAG and persistent folder Knowledge Base running directly on your own infrastructure (Docker Desktop + Ollama) for Windows technical users.

Best for: Windows developers & researchers who want full control over containers, local vectors, and host Ollama models.

⚡ Start in 5 Minutes

  1. 1 Extract the ZIP package completely to a folder (e.g. C:\StarkLLM\).
  2. 2 Open terminal in folder — click the address bar, type cmd, press Enter.
  3. 3 Run start.cmd (or double-click start.exe).
  4. 4 If Windows blocks scripts: run powershell -ExecutionPolicy Bypass -File unblock.ps1
    (Unblocks extracted files strictly inside the local folder).
  5. 5 Then run start.cmd — access browser at http://localhost:5173.

Important Notes

  • ⌛ First launch takes longer: Docker must download container images initially.
  • ⚠️ Windows SmartScreen: If execution is blocked, use start.exe or run unblock.ps1 (see Download page).
  • 💻 Hardware matters: Speed and answer quality depend heavily on having a capable GPU (8GB+ VRAM recommended).

The Command Center

The Dashboard provides immediate visibility into your local intelligence ecosystem. Navigate seamlessly between distinct workspaces and monitor system status in real-time.

  • Workspace Isolation: Separate your research projects, coding tasks, and legal document reviews into hard-bounded workspaces to prevent context contamination.
  • Live System Status: Monitor your vector database health, backend connectivity, and Ollama inference engine uptime at a glance.
  • Instant Access: Jump directly into recent chat threads or review the documents currently indexed in your active workspace.

Document-Aware Intelligence

Experience chat that is grounded in your documents. StarkLLM bridges the gap between open-weight LLMs and your personal or enterprise documents.

  • Source-Grounded Answers: The AI retrieves precise semantic chunks from your uploaded PDFs before generating an answer, helping reduce unsupported answers.
  • Transparent Citations: Responses typically include direct references to the original source document, allowing you to trace the AI's logic instantly.
  • Multi-Chat Sessions: Maintain parallel, distinct conversations within the same workspace to explore different hypotheses simultaneously.

The Architecture of Privacy

StarkLLM offers an alternative to the cloud-dependent paradigm. Your enterprise data, legal briefs, and personal research may be too sensitive to transmit to remote APIs where they could be used for future model training.

Local Inference

Powered by Ollama, Large Language Models run directly on your own CPU or GPU. Designed to work fully offline once models are downloaded.

Local Storage

Your documents are chunked and embedded into a local ChromaDB vector store running inside an isolated Docker container.

Minimal Telemetry

StarkLLM does not include built-in tracking or analytics. Core AI functionality is designed to operate without remote dependencies.
